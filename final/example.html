HTML concepts

nav

It is like a container for the menu links. I used it to hold About, Store, Gmail, and Images at the top.

ul and li

ul is a list, li is one thing in that list. I used them to make the two groups of links in the nav, (About and Store) and (gmail and Images)

h1, h2, h3

They are titles. h1 is the biggest, and the texts get smaller as the number after the h goes higher. You can see the differnece in the size of the text.

span

It wraps a small piece all together and shows the text in one line. I used it on each letter of Google so they can be different colors but still in the same line.

div

It is just a box to group things together. I used it to group the search bar and the two greeting buttons in the middle so that i can edit them effectively.

class

It is a name you give to an element so CSS can find it. I used it to group the components however I want and to edit effectively.
All the green boxes here are all grouped together.

footer

It is the bottom part of the page. I used it to put the policy and terms links and this explanation down here becasue I wanted to put them at the bottom, not top of the page.

CSS concepts

tag selector

A tag is the name of an HTML element. When you write h2 in CSS it styles all h2s on the page at once so I don't need to style every single tag.

class selector

A dot before the name means only style elements with that class. I used .button to change the style of all the buttons.

display: flex

It makes things go side by side instead of one under the other. I used it so the nav links and footer links sit in a row.

justify-content

It decides where things go inside a flex row. I used it to push the nav links to opposite sides and the footer links to the right.

margin: 0 auto

It puts equal space on both sides to center something. I used it to put the search bar in the middle of the page.

color

It changes the text color. I used it to give each letter of Google its own color like blue, red, and green.

background-color

It is the color behind the text. I used it to make the search bar white and the buttons grey. This green box is also colored by background-color.

border-radius

It makes the corners round. I used it to make some boxes look round and kept some boxes sharp

box-shadow

It adds a soft glow around an element. I used it to give the search bar a blue glow for a visual separation.

padding and margin

Padding is space inside the box, margin is space outside the box. I used padding to make some space inside the boxes and margin to create breath room.

font-size and font-weight

font-size is how big the text is, font-weight is how thick it is. I used them to make the website more dynamic.

list-style-type: none

It removes the dots that normally show in a list. I used it so remove dots in front of About and gmail as unnecessary dots appeared.
